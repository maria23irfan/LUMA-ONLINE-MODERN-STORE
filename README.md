# 🛍️ LUMA — Modern E-Commerce Website

A modern, responsive, and interactive **fashion e-commerce website** built with HTML, CSS, and JavaScript.

LUMA features a clean and premium shopping experience with product categories, featured collections, a shopping cart, wishlist interactions, promotional sections, and smooth scroll animations.

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/your-username/luma-ecommerce.git
```

### 2. Open the project

Open the project folder in **VS Code** or another code editor.

### 3. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for easier development.

---

## 🌍 Deployment

The website can be deployed using **GitHub Pages**.

After uploading the project to GitHub:

1. Open your repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Choose your main branch.
5. Select the root folder.
6. Save the settings.
7. GitHub will generate a live website URL.

Add your generated URL to the **Live Demo** section above.
